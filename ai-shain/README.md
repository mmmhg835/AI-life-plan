# AI社員、働いてます。／ CLAUDE WORKS INC.

Claude Code のサブエージェントを、みなも町で働く10名の社員として眺めるためのページ。
`index.html` の1枚だけで動きます（ライブラリ・ビルド・通信なし）。

開き方は、ファイルをそのままブラウザにドロップするだけ。
Vercel に載せている場合は `/ai-shain/` で見られます。

## 何が起きているか

- **社員10名** … それぞれ Claude Code のサブエージェントに対応します。

  | 社員 | 担当 | サブエージェント |
  |---|---|---|
  | 建部 設 | 設計 | `Plan` |
  | 中原 汎太 | なんでも | `general-purpose` |
  | 探田 索 | 調査 | `Explore` |
  | 万代 汎 | 遊軍 | `claude` |
  | 意匠 彩 | 意匠 | `artifact-design` |
  | 案内 導 | 案内 | `claude-code-guide` |
  | 蔵本 収 | 台帳 | リポジトリ・履歴まわり |
  | 校谷 正 | 校閲 | `code-review` |
  | 救島 助 | 救援 | デバッグ |
  | 整野 備 | 整備 | 環境構築・テスト |

- **社内の仕事**は自席で片づきます。頭上のバーが進み具合。
- **客先の仕事**は町を歩いて出張します。取引先は3社（みなも堂菓子舗／緑岸精密板金／向井田社会保険労務士事務所）。
- 下の欄に日本語で仕事を投げると、語をたよりに担当が決まり、最大3工程に分けて順に流れます。
  取引先の名前が入っていれば、その社まで出張します。
- 手が空いた社員は、たまに公園へ息抜きに行きます。

## 操作

| | |
|---|---|
| ドラッグ | 視点の移動 |
| ホイール | 拡大・縮小 |
| 社員をクリック | 名指し（視点が追いかけます） |
| 上のタブ | 会社・公園・各取引先へ寄る |
| 速度 | 一時停止／×1／×2／×4 |

社内時刻は実時間1秒あたり2分進みます（×1のとき）。

## 二つのモード

**模擬（既定）** — 隣に `events.jsonl` が無いとき。町のできごとは全部作り話です。発注欄も使えます。何もつながっていないので当然無料です。

**実況** — 隣に `events.jsonl` があるとき。Claude Code のフックが書き出した本物の出来事が流れてきて、右下が `● LIVE` になります。作り話は止まり、発注欄は塞がります（ブラウザから Claude Code に仕事を押し込むことはできないため、こちらは見る専用です）。

実況でも**追加料金はかかりません。** 使うのはシェルを走らせるだけのフックで、モデルを呼ばないからです。つなぎ方は `live/README.md` にあります。

実況中の社員は、`.claude/agents/` に定義した本物のエージェント名で表示されます。**席は先着順の自動割り当てなので、どんな役職を定義してもそのまま町に出ます。** 議論する社員の例は `agents/` にあります。

## 手を入れるとき

`index.html` の中は上から順に、
社員名簿 → 取引先 → 町の地形 → 経路探索 → 社員の実体 → 仕事 → 時計 → 描画 → 画面の更新 → 操作、
と並んでいます。社員や取引先を増やすだけなら先頭の配列だけで足ります
（社員を増やすときは、机の並びが2列5席なので `SEATS` の作り方も合わせてください）。
