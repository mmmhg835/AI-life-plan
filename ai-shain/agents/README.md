# 役職を差し替える

町の席は先着順の自動割り当てなので、**ここに置いた役職がそのまま社員として町に出ます。**
コードを書く社員（探田・建部…）ではなく、議論する社員が欲しいときはこちらを使ってください。

```sh
cp ai-shain/agents/*.md ~/.claude/agents/     # 全プロジェクトで使う
cp ai-shain/agents/*.md .claude/agents/       # このプロジェクトだけ
```

入れたあと、Claude Code に普通に相談すると、内容に応じて本体が担当を呼び分けます。

> 新商品の値付けをどうするか考えたい。論点を整理して、競合も調べて、数字の裏取りもして。

`description` に「いつ呼ぶか」を書いてあるので、明示的に指名しなくても本体が判断します。
呼ばれない・呼ばれすぎるときは `description` の書き方を調整してください。
