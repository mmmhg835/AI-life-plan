# 名刺カバレッジ

名刺を入れると、**企業ごとの箱**が自動でできて、**接点の有無**・**組織図**・**どこまで営業できているか**が
そのまま見えるようにしたツール。`cards/index.html` の1ファイルで動く（ビルド不要）。

ブラウザで `cards/index.html` を開くか、Vercel に載っていれば `/cards` で開く。
データはそのブラウザの localStorage と IndexedDB にだけ入る。**サーバには何も送らない。**
外部のAPIも使わないので、**動かすのにお金はかからない。**

まず「取り込み／保存」タブの「サンプルデータを入れる」を押すと、動きが一通り見える。

---

## 画面

| タブ | 中身 |
|---|---|
| ダッシュボード | 全体のKPI、ステージ分布、いま追いかけるべき企業、名刺だけで止まっている企業 |
| 企業 | 企業の箱の一覧。カバレッジ・接点状態・直近12か月のスパークライン付き。押すと企業カルテ |
| 接点マップ | 到達マップ（企業×役職の層）、接点ヒートマップ（企業×直近12か月）、自社担当ごとの持ち分 |
| 名刺 | 登録フォームと、名刺の見た目で並ぶ一覧（表にも切替可）。1枚押すと人物プロフィール |
| 接点 | 接点の記録フォームと全履歴 |
| 取り込み／保存 | CSV・名刺テキストの取り込み、書き出し、判定ルールの設定、サンプル投入・全削除 |

**名刺の見た目**：写真があればその写真、無ければ名刺サイズに会社・部署・役職・氏名・連絡先を組んだ面を出す。
面の左端の色が接点の状態（緑＝接点あり／黄＝冷えかけ／赤＝途絶／灰＝名刺のみ）。

**人物プロフィール**：名刺の面、連絡先（メール・電話はそのまま発信できるリンク）、
役職の層、この人との接点履歴、その場での接点記録、同じ会社の人が並ぶ。
組織図の人物カード・一覧の氏名・接点履歴の氏名、どこから押してもここに来る。

**名刺の写真**：スマホなら「写真を選ぶ／撮る」でカメラが開く。長辺1000pxのJPEGに縮小して保存する。
保存先は IndexedDB（使えない環境では localStorage に退避）。JSON書き出しには写真も含まれる。

**明るい／暗い**：右上のボタンで切り替わる。触らないうちはOSの設定に従う。

## 見た目の決めごと

数字を読む道具なので、飾りではなく**判読**に寄せている。

- **色**：紙 `#eef0f3` / 面 `#ffffff` / 墨 `#0f1318` / 罫線 `#d8dce2`、アクセントはコバルト `#1546e0`。
  暗いほうは 地 `#0a0c0f` / 面 `#12161b` / 罫線 `#242b33` / 文字 `#e7ebf0`、アクセント `#5b8cff`。
  色は状態（接点あり・冷えかけ・途絶）にだけ使い、装飾には使わない。
- **持ち方**：色はCSS変数で名前だけ決めてあり、明暗で中身を差し替える。
  画面側が `var(--green)` と書けば、暗い配色でも自動で読める緑になる。
- **角と線**：角丸は3px。影は使わず1pxの罫線で仕切る。KPIは箱を並べず、罫線で割った一本の帯にしている。
- **文字**：Noto Sans JP（見出しと氏名は900）。数字・日付・ラベルは DM Mono で、桁が縦に揃うようにしている。
- **記号**：状態は四角のマーカーで示す（絵文字は使わない）。名刺の面と人物カードの左端の色が、その人の接点の状態。

## 自動でやっていること

### 1. 企業の箱づくり（会社名の表記ゆれ吸収）

会社名を正規化してキーにし、同じ会社を1つの箱にまとめる。

- `株式会社サンプル` / `サンプル（株）` / `サンプル(株)` / `ｻﾝﾌﾟﾙ` → 同じ箱
- 法人格（株式会社・有限会社・合同会社・一般社団法人・Inc/Ltd/LLC など）、空白、
  中黒・ハイフン類、大文字小文字の違いを落としてから比較する

読みが同じでも表記が違う（例：`青空リース` と `あおぞらリース`）ものは**別会社として扱う**。
そこまで寄せると別会社を誤って混ぜるため。混ぜたい場合は名刺側の会社名を揃える。

### 2. 接点の有無と鮮度

名刺を登録した時点で「名刺交換」という接点が1件自動で入る。そのうえで、

| 表示 | 条件 |
|---|---|
| 名刺のみ | 名刺交換以外の接点が1件もない |
| 接点あり | 最終接点が **90日以内**（変更可） |
| 冷えかけ | 91〜365日（変更可） |
| 途絶 | 365日超 |

企業単位と人単位の両方で判定する。組織図の人物カードの左色がこの状態。

### 3. 組織図

名刺の「部署」を階層として読む。`/` `／` `>` `|` `・` と空白（半角・全角）が区切り。

```
営業本部/第一営業部/東京1課   →  営業本部 ─ 第一営業部 ─ 東京1課
営業本部　第一営業部          →  営業本部 ─ 第一営業部
```

部署が空の名刺は会社直下に置く。同じ箱の中では**役職ランク順**に並ぶ。

役職ランクは 1〜12（1が上）。`会長 1 / 社長 2 / 副社長 3 / 専務 4 / 常務 5 / 取締役 6 /
執行役員・本部長 7 / 部長 8 / 次長 9 / 課長・室長 10 / 係長・主任 11 / 担当 12`。
役職が空、または表にない語は 12 になる。

**決裁層** の境目は既定でランク7（執行役員・本部長以上）。「取り込み／保存」タブで変えられる。
ただしこれは推定なので、会社ごとに「決裁者」タグで上書きできる（→ 6.）。

### 4. 営業ステージ

接点履歴のうち **一番進んだ種類** をその企業のステージにする。

`名刺交換・メール → 名刺のみ` / `電話・訪問・打合せ → 接触・訪問` / `ヒアリング` /
`提案` / `見積提出` / `受注`。最新の接点が「失注」なら失注。
企業カルテで手動に切り替えれば固定できる。

### 5. カバレッジ（0〜100）

「どこまで入り込めているか」を1つの数字にしたもの。内訳は：

| 配点 | 見るもの |
|---:|---|
| 25 | 名刺の枚数（3枚で満点） |
| 15 | 部署の広がり（第1階層で3部署あれば満点） |
| 25 | 上への到達（決裁層に名刺あり＝25／キーマンのみ＝18／管理層まで＝10） |
| 15 | 鮮度（接点あり＝15／冷えかけ＝7） |
| 20 | ステージ（受注で満点） |

企業一覧はこの値の**低い順**が初期表示。伸びしろの大きい会社が上に来る。

### 6. 決裁者・キーマンのタグ

役職ランクは**会社をまたいだ推定**でしかない。誰が決裁者かは会社ごとに違うので、タグで上書きできる。

名刺に付けられるタグ：`決裁者` `キーマン` `窓口` `紹介者` `反対` ＋ 自由なタグ。
人物ページのボタンは押した瞬間に保存される（入力フォームのタグは登録ボタンを押すまで保存しない）。

**「決裁者」タグを1枚でも付けた会社は、その会社だけ役職からの推定をやめる。**

| 会社の状態 | 決裁層の決まり方 |
|---|---|
| 「決裁者」タグあり | タグを付けた人だけが決裁層。ほかは役職ランク10以下なら管理層、それ以外は実務層 |
| タグなし | これまで通り、役職ランクが設定値（既定は執行役員・本部長）以上なら決裁層 |

例：本部長と部長の名刺がある会社で、実際に決めるのが部長なら部長に「決裁者」を付ける。
すると部長が決裁層、本部長は管理層に下がる。組織図では `★決裁`（タグ）・`◆キーマン`・`★`（役職からの推定）で区別する。

キーマンは層を動かさないが、決裁者が未特定でもカバレッジの「上への到達」を 18/25 点まで押し上げる。
企業一覧は「決裁者：タグで特定済み／未特定／決裁層に未到達」で絞り込める。

### 7. 接点マップ

- **到達マップ**（企業 × 決裁層／管理層／実務層）：セルの色はその層で一番新しい接点の状態、
  数字はその層の名刺枚数。**斜線＝その層の名刺をまだ持っていない**＝空白地帯。
  左の列（決裁層）が緑になっていない会社は、決裁に届いていない。
- **接点ヒートマップ**（企業 × 直近12か月）：月ごとの接点件数を濃さで出す。
  横に途切れている期間が、その会社を放置していた期間。
- **自社担当ごとの持ち分**：担当企業数、そのうち接点が生きている数と割合、決裁層に届いている数。

## 取り込み

- **CSV／タブ区切り**：1行目の見出しから列を自動で判別する（会社名・氏名・タグは見出しから判別）。
  Excelからそのままコピー＆ペーストでも入る。同じ会社・同じ氏名は重複としてスキップ。
- **名刺の文字起こし**：OCR結果やメール署名を貼ると、空行区切りで1枚ずつ読む。
  会社名・氏名・役職・部署・メール・電話を**推測**するので、取り込み後に名刺一覧で直す前提。

  お金をかけずに名刺の文字を起こすなら、**スマホの標準機能**が使える。
  iPhoneなら写真アプリで名刺を開いて文字を長押し（テキスト認識表示）、
  Androidなら Google レンズ。選んでコピーし、この欄に貼って空行で区切れば取り込める。

書き出しは JSON（全データ・バックアップ用）、名刺CSV、企業カバレッジCSVの3種類。

## テスト

Playwright で実ブラウザから流す。110件。

```bash
npm i playwright
node cards/test/browser-test.js
```

Chromium の場所は `PW_CHROMIUM` 環境変数で指定できる（未指定なら Playwright の既定）。

## 分かっている制約

- 保存先はブラウザだけ。**別のPC・別のブラウザとは共有されない**し、キャッシュを消すと消える。
  複数人で使うならJSON書き出しで受け渡すか、サーバ保存を足す必要がある。
- **名刺の写真を撮っても、文字は自動では読み取らない**。画像から項目を起こすには
  外部のOCR（有料API）かサーバが要るので入れていない。写真は名刺そのものの控えとして持ち、
  項目はフォームに入力するか、スマホの文字認識でコピーして「名刺の文字起こしから取り込む」に貼る。
- 組織図は「もらった名刺の部署名」から組み立てているだけで、実際の指揮命令系統ではない。
  名刺を持っていない部署は存在しないものとして描かれる。
- 役職ランクは日本語の一般的な肩書きに合わせた対応表。外資系の肩書き（VP、Director など）は
  今は「担当」（12）に落ちる。
